# 🎮 Unity Essentials - Learning Pathway

Welcome to my repository for the **Unity Essentials** learning pathway! This repository documents my journey through Unity’s official beginner curriculum, showcasing the projects, scenes, and exercises I built while learning how to navigate the Unity Editor and master foundational game development concepts.

---

## 📖 Pathway Overview
Designed for anyone new to Unity, this guided learning journey serves as a stepping stone toward creating confidently in the Unity Editor and bringing creative visions to life. Throughout this pathway, I designed different rooms of a house and worked through interactive playground scenes, mastering the essentials of core skill sets as each project was completed.

---

## 🗺️ Curriculum & Missions Covered

This pathway is divided into comprehensive missions and skill-building modules:

### 1. 🧭 Editor Essentials
* **Installation & Setup:** Installing Unity, setting up the Hub, and opening project files.
* **Interface & Navigation:** Exploring the Unity Editor interface, mastering 3D scene navigation, and passing the Scene view flying test.
* **Creative Exercise:** Designing a custom mural directly within the Scene view.

### 2. 🧊 3D Essentials
* **GameObjects & Transforms:** Working with primitive shapes, positioning, rotation, and scaling.
* **Scene Building Essentials:** Assembling 3D environments, managing hierarchies, and organizing assets effectively.

### 3. 🎵 Audio Essentials
* **Sound Integration:** Importing audio clips and configuring Audio Sources and Audio Listeners to build atmospheric environments.

### 4. 💻 Programming Essentials
* **Code Comprehension:** Introduction to Level 1 application scripting and reading C# code behavior.
* **Project Management:** Creating, organizing, and maintaining clean Unity project structures.

### 5. 🎨 2D Essentials
* **2D Art & Sprites:** Working with 2D assets, sorting layers, and configuring sprites.
* **Beginner Cameras:** Setting up orthographic and perspective cameras for 2D gameplay views.

### 6. 🚀 Publishing Essentials
* **Deployment & Sharing:** Learning the fundamentals of building, packaging, and preparing Unity projects for publishing.
